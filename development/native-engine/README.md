# ATREZZO Native Engine — foundation 0.1

Migration-only. No visual changes, deployment or replacement of approved Home V06. New code is isolated in this directory. No captured proprietary application source, CSS, shaders or geometry included here. Do not distribute historical captured/adapted material or assume permission.
